# Recepcionista IA

Recepcionista comercial con IA para WhatsApp. Nicho inicial: clínicas odontológicas.

Empezá por `docs/00-EMPEZAR-ACA.md`. El plan de trabajo está en `docs/PLAN.md`.
Claude Code lee `CLAUDE.md` y `.claude/` automáticamente.

```
docs/00-EMPEZAR-ACA.md      qué hacer vos, en orden
docs/PLAN.md                fases y tareas con verificación
docs/ARQUITECTURA.md        carpetas, flujo, loop del agente
docs/DISENO.md              sistema de diseño del panel
docs/FLUJO-CLAUDE-CODE.md   cómo trabajar con Claude Code (contexto, loops, subagentes)
docs/ONBOARDING-CLINICA.md  formulario de alta de clínica
docs/DECISIONES.md          decisiones tomadas
supabase/migrations/        esquema
supabase/seed/              Clínica Dental Nova (demo)
prompts/recepcionista.md    system prompt base
scripts/scenarios/          escenarios de conversación (tests del agente)
.claude/                    settings, reglas, subagentes, skills
```
